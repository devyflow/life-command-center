# Changelog

All notable user-facing changes will be recorded here.

## [Unreleased]

### Added

- A visible daily path from quick capture through weekly and daily planning to focused work and review.
- Title-only quick capture that safely sends new tasks to Inbox.
- A This Week queue with direct promotion into Today.
- A Needs Review filter for unclear or repeatedly postponed tasks.
- Plain-language definitions for every task signal.
- Repository checks and contributor guidance for pull-request development.

## [0.9.0] - 2026-10-25

### Added

- Authenticated, synchronized personal and tester workspaces.
- Today, hourly planner, Inbox, All Tasks, Paper, Bulletin, Useful Library, Insights and time-request views.
- Task editing, categories and subcategories, progress locks, completion confirmation and recovery history.
- Weekly, important, ready, protected-time and today-focus task signals.
- Installed web-app experience, offline shell, update prompts and configurable accent color.
- Page scanning with editable OCR review and task suggestions from photos and links.
